Rules shown here: the target's own figures are used, so the % is the same number as on the Quantity Targets page. A target in another unit than the material's tiles is still shown in its own unit. Cancelled targets are left out. Near target is amber, over target is red, and the words "Over target by" say it in black and white. The option is off by default and only adds tiles; nothing else in the PDF changes.
