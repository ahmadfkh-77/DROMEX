Workflow

1 · OPENTap + . Sheet shows PROJECT line (name or "None chosen") and the ten actions.
2 · TAP PROJECT LINESheet content swaps to the picker. No navigation, sheet stays open, Back returns to actions.
3 · SEARCH / PICKFilter by name, customer or location. Tap a row: runs the same chooseActiveProject as the Projects screen, persisted for next launch.
4 · RETURNPicker closes, sheet shows the new name with "Change". Needs-project tags vanish. Context bar appears under the status bar as it does today.
5 · ACTProject Issue / Site Photo open the project's Issues / Photos panel directly. Other eight actions behave as today (they prefill the active project).
6 · CHANGE / CLEAR"Change" reopens the picker with the current project ticked. "No project" row clears it (the app's context bar already offers Clear today).
7 · EMPTYNo active projects: empty-state card, "Open Projects" closes the sheet and goes to Projects.

Component choice: the picker is drawn inside the sheet (a view state, not a second Modal on top of the Modal) using the same row and search styling as SearchableSelect (name, with customer · location detail, as in the Pavement and Schedule project selectors). Active projects only.
