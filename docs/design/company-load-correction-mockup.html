What stays exactly the same

  • Every rule, check and lock of today's correction: the same fields, the payment locks, the required reason, the saved original and the load number and transaction number that never change. Saving uses the same correction as today.
  • The quantity method (weighbridge or direct) stays as confirmed. Issued documents keep their own copy; only future PDFs and reprints use the corrected values.
  • No database change for the look. Counts toward target adds the target to the fields a correction can change, recorded in the history like every other field (needs a small repository change, no new table).
  • I would show Preview documents with the same document view Make Receipt uses.
