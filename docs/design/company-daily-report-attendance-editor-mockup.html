What changes
  • Clear marking: worked = navy tick box and the word "Worked", on the same white row (no colour band, no side line). Not worked = empty box and "Not today". The tick and the word carry the meaning, not only colour.
  • A small plain + on every row (people, trucks, machines): just the + sign, no box and no circle. The touch area stays 48 x 48. No "+ Place" button inside the list and no panel at the bottom of the page.
  • Bottom sheet for that one entry: search, Projects (active only), Company sites, and "Type a place". Tap a place to add it (it shows "Added ✓"), tap again to remove it. The sheet stays open so several places go in a row. Done closes it.
  • Adding a place marks the person as worked automatically.
  • Chips under the row show the places; tap a chip to remove it. A typed place has an orange tint.
  • Each section says "x of N worked".
  • Save attendance at the bottom saves all changes together.
